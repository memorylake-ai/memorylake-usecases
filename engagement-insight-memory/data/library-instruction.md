# What to record in this project
This is Calder Lane's firm-level insight library. It must never contain anything that identifies a client.

## Record
- Generalizable patterns, diagnoses and frameworks that worked, stated so they apply to any client in the sector.
- Describe the client only by sector and size (e.g. "a mid-size regional grocer"), never by name.

## Exclude / rewrite
- Never record client company names, brand names, store or city names, or the names of any person.
- Never record exact figures (percentages, amounts, store counts, dates of the engagement); use directional language ("margin roughly halved").
- If a statement cannot be made without a client identifier, do not record it.
