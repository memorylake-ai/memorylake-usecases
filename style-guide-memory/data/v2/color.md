# Kestrel UI - Color

Version 2.0, approved 2026-10-13 by Mira Okafor (color lead).

Primary button color is Copper 400 (#C8743A). Use it for exactly one primary action per screen.

Error text and error borders use Signal Red 600 (#C2362B). Never use red for anything that is not an error.

Body text on light surfaces is Ink 900 (#1B1F24). Text must meet a 4.5:1 contrast ratio against its background.
