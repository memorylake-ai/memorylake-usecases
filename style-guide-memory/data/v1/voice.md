# Kestrel UI - Voice and microcopy

Version 1.3, approved 2026-07-14 by Sam Whitlow (content design).

Write error messages that say what happened and what to do next. Never write "Oops" or "Something went wrong".

Empty states name the thing that is missing and offer one action to create it.

Use "you" for the customer and "we" for Kestrel. Never use exclamation marks in product copy.
