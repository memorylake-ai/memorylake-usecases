# Protocol CVT-118-201 - Prohibited medicines and washout

Owner: Medical monitor, Corvane Therapeutics. Version 2, effective 2026-08-15.

Strong CYP3A4 inhibitors (for example clarithromycin, itraconazole, ketoconazole) must be stopped before the first dose of CVT-118. The first CVT-118 dose may be given no earlier than 14 calendar days after the last inhibitor dose.

Grapefruit juice is not allowed from screening until the end-of-study visit.
