# Protocol CVT-118-201 - Serious adverse event reporting

Owner: Pharmacovigilance, Corvane Therapeutics. Version 2, effective 2026-08-15.

Report every serious adverse event (SAE) to Corvane pharmacovigilance within 24 hours of the site first becoming aware of it, using the SAE form in the trial portal. A follow-up report with the outcome is due within 7 calendar days of the first report.

Pregnancies are reported on the same timelines as SAEs.
