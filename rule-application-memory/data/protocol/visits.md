# Protocol CVT-118-201 - Visit schedule

Owner: Clinical operations, Corvane Therapeutics. Version 4, effective 2026-09-10.

Day 1 is the day of the first infusion. The safety follow-up visit is on Day 29, with a window of 3 days either side (Day 26 to Day 32). Visits outside the window are protocol deviations and must be logged within 5 working days.

The end-of-study visit is on Day 85, window 7 days either side.
