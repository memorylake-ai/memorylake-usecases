# Protocol CVT-118-201 - Liver safety rules

Owner: Medical monitor, Corvane Therapeutics. Version 2, effective 2026-08-15.

The site laboratory upper limit of normal (ULN) for ALT is 40 U/L. Hold the weekly dose if ALT is more than 3 times the ULN. Stop CVT-118 permanently if ALT is more than 5 times the ULN, or more than 3 times the ULN with total bilirubin above 2 times its ULN.

Repeat liver tests within 72 hours of any held dose.
